MCEconomy

Change log

This page always mirrors the latest MCEconomy release. Every version also has a permanent link in the version index.

1.1.0 Latest 2026-08-01
Added
  • Support for running on Folia alongside SpigotMC and PaperMC from the same universal jar. The engine detects the server at start-up and installs the matching scheduler.
Changed
  • MCEconomy no longer needs the MCIdentity developer artifacts to build. The identity integration is now resolved at runtime through the MCIdentity plugin itself, so the two plugins can be updated independently.
  • Plugins that build against the published api, common, and bukkit libraries no longer inherit an MCIdentity dependency.
Fixed
  • The build failed outright because it referenced MCIdentity 2.0.0, which is no longer published. MCEconomy now targets MCIdentity 4.0.1 at runtime and pins no version at build time.
Notes
  • Upgrading from 1.0.0: install MCIdentity 4.0.1 or newer. No config, command, currency, or wallet behaviour changed, and no data migration is required.
  • If MCIdentity is missing or too old, MCEconomy now logs the problem once and leaves identity wallets unavailable instead of failing to start.
