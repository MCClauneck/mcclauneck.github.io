MCSlayerRewards

MCSlayerRewards pays players for killing mobs. You decide, mob by mob, how much money a kill is worth, which currency it pays in, and which extra items drop. The reward floats above the kill so the player sees it straight away.

Version 1.3.0 Requires MCIdentity and MCEconomy Minecraft 1.21 or newer SpigotMC, PaperMC, FoliaMC

What happens when a mob dies

Rewards only apply when a player lands the killing blow, and only for mob types you have set up. Every other mob behaves exactly as normal.

1

Drops are rolled

If vanilla drops are switched off for this mob, they are cleared. Each custom drop then rolls its own chance and is added to the loot when it succeeds.

2

Money is worked out

A fixed amount is paid as is. A range picks a new random amount for every kill. If the amount is zero or missing, no money is paid.

3

The character is paid

The money goes to the MCIdentity character the killer is using, in the mob's currency. Players with no active character get the drops but no money.

4

The reward appears

A plus sign, the amount, and the currency float just above the death spot for a moment and then disappear. Nearby players can see it too.

💡

A mob with no currency chosen pays in Coin. If its currency does not exist in MCEconomy, the money part of the reward is skipped and a warning is written to the server log. Another plugin can also block a payout, in which case nothing is paid.

The reward editor

Admins open the editor with the edit option of the slayer rewards command, followed by a mob type such as zombie, skeleton, or blaze. A shorter slayer alias works too. If the mob has no rewards yet, it starts with no money and Coin as its currency.

In the editorWhat it does
Place an item in the top rowsAdds it as a custom drop, keeping every detail of the item.
Shift and right click a dropAsks in chat for its drop chance, from 0 to 100 percent.
Currency headMoves the mob's reward to the next MCEconomy currency.
Vanilla drops buttonTurns the mob's normal drops on or off.
Reward amount buttonAsks in chat for the money reward, either one number or a low and high number joined by a dash.
Save and Reload headSaves the page and refreshes the editor.
Arrow headsSave the page and move to the previous or next page of drops.

Each page holds 45 drops. Chances above 100 or below 0 are capped to fit, and a chance that is not a number cancels the change. Each mob's rewards are saved in their own file, named after the mob, so you can also edit them by hand.

The command is for admins only and needs the slayer rewards admin permission. Players never need a command, because rewards are handed out automatically.

Setup and storage

MCSlayerRewards is a normal plugin that runs next to MCEconomy and MCIdentity. The server loads both of them before it.

  1. Install MCIdentity and MCEconomy first.
  2. Add the MCSlayerRewards plugin file and start the server once to create its settings file.
  3. Turn on the master switch in the settings file. A fresh install ships switched off and creates no data until you turn it on.
  4. Choose where the kill and reward history is stored, then restart.
Local file default

A database file inside the plugin's folder. Nothing to set up.

MySQL, PostgreSQL, or MongoDB

A shared database, reached with its address and login, exactly as in MCEconomy.

Central server

Every mob a player kills and every payout is recorded on the MCEconomy central server, giving your network one history. If its address is left empty, MCSlayerRewards warns you and keeps the history on this server only.

If MCEconomy or MCIdentity is missing or not ready, MCSlayerRewards says so once and stops paying money instead of breaking the server. The server needs Java 25.
