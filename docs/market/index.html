MCMarket

MCMarket is a chest-menu shop for your server. Players buy and sell items with a click, paying in any MCEconomy currency, and admins build each shop by dragging items into an in-game editor.

Version 1.3.0 Requires MCIdentity and MCEconomy Minecraft 1.21 or newer SpigotMC, PaperMC, FoliaMC
Change log Repository ↗

Highlights

🛒
As many markets as you want. Make one for ores, one for food, one for blocks. Each market can hold any number of pages.
🖱️
Built in game. Drag items into the editor and set prices from chat. No settings file needs to be touched.
🪙
Any currency, per item. Every item chooses its own MCEconomy currency, so one market can mix coins and tokens.
🧬
Items stay exactly as made. Enchantments, custom names, durability, and every other detail are saved with the item.
⚡
No lag. Money and database work happen in the background, away from the game itself.
🗄️
Five places to keep data. A local file by default, or MySQL, PostgreSQL, MongoDB, or the MCEconomy central server.

Shopping in a market

A player opens a market by typing the market command followed by the market's name, and can add a page number to jump straight to that page.

👀

Browse

The market opens as a large chest. The top five rows show up to 45 items, each with its buy price, sell price, and currency written underneath. A side that is switched off shows as not available.

🛍️

Left click to buy

You need at least one empty inventory slot. The price comes out of your current character's wallet and the item goes into your inventory.

💰

Right click to sell

You need the item in your inventory. It is taken, and the sell price is paid to your current character. If the payment fails, the item is given back.

📖

Turn pages

Arrow heads in the bottom row lead to the previous and next pages when they exist.

🧍

Money always belongs to the MCIdentity character a player is using. A player with no active character is asked to choose one first. Another plugin can also block a purchase or sale, and the player is told when that happens.

Building a market

Admins create a new market with the create option of the market command and change an existing one with the edit option. Both open the same editor.

In the editorWhat it does
Drag an item into the top rowsAdds it to the market, exactly as it is, including the stack size.
Shift and left click an itemAsks for the buy price in chat.
Shift and right click an itemAsks for the sell price in chat.
Middle click an itemMoves the item to the next MCEconomy currency.
Save and Reload headSaves the page and refreshes the editor.
Arrow headsSave the page and move to the previous or next page.

When you are asked for a price, type a whole number in chat. Typing minus one switches that side off, so an item can be buy only or sell only. Closing the editor also saves your changes. Every item in the editor shows its current prices and currency, plus a reminder of these controls.

Each market is saved as its own file in the plugin's folder, named after the market. On first start MCMarket creates an example Ore Market so you can see how one looks. The files can be edited by hand if you prefer, but the editor is the intended way.

Commands and permission

Open a market
The market command with a market name, and optionally a page. Every player can use it.
Create a market
The market command with the create option and a new name. Refused if that name is taken.
Edit a market
The market command with the edit option, a market name, and optionally a page.
Admin permission
Creating and editing need the market admin permission. Browsing, buying, and selling need nothing.
Suggestions
While typing, the command suggests existing market names. Admins also see the create and edit options.

Setup and storage

MCMarket is a normal plugin that runs next to MCEconomy and MCIdentity. The server loads both of them before MCMarket.

  1. Install MCIdentity and MCEconomy first.
  2. Add the MCMarket plugin file and start the server once to create its settings file.
  3. Turn on the master switch in the settings file. A fresh install ships switched off and creates no data until you turn it on.
  4. Choose where market data is stored, then restart.
Local file default

A database file inside the plugin's folder. Nothing to set up.

MySQL, PostgreSQL, or MongoDB

A shared database, reached with its address and login, exactly as in MCEconomy.

Central server

Every saved market is also copied to the MCEconomy central server, so your network has one record of every shop. If the central server's address is left empty, MCMarket warns you and keeps markets on this server only.

If MCEconomy or MCIdentity is missing or not ready, MCMarket says so once and leaves trading switched off instead of breaking the server. The server needs Java 25.
