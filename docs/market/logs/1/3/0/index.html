Version 1.3.0

A permanent link to the MCMarket 1.3.0 release notes.

1.3.0 Latest 2026-08-01
Added
  • Full Folia support. MCMarket now runs on SpigotMC, PaperMC, and Folia from the same universal jar, which detects the server at start-up and installs the matching scheduler.
Changed
  • MCEconomy and MCIdentity are no longer build dependencies. Both are resolved at runtime through the running plugins, so all three can be updated independently of one another.
  • Building the plugin from source no longer requires GitHub credentials.
Fixed
  • Reopening the market editor and completing a purchase or sale used the global server scheduler, which does not exist on Folia.
  • The build failed outright because it referenced MCIdentity 2.0.0, which is no longer published. The plugin now targets MCIdentity 4.0.1 and MCEconomy 1.0.0 at runtime, pinning neither at build time.
Notes
  • Upgrading from 1.2.0: install MCIdentity 4.0.1 or newer. No config, command, or stored-data behaviour changed, and no migration is required.
  • If a host plugin is missing or too old, the problem is logged once and the affected feature is skipped, rather than the plugin failing to load.
