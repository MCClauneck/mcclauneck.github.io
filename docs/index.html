MCClauneck ecosystem

A per-identity economy for Minecraft servers

MCEconomy gives your server as many currencies as you like and keeps a separate wallet for every MCIdentity character a player owns. MCMarket adds a chest-menu shop, and MCSlayerRewards pays players for killing mobs.

How it fits together

One identity, one account

💡

MCIdentity lets one player own several characters. MCEconomy gives each character its own wallets, so money follows whichever character the player is using. MCMarket and MCSlayerRewards are separate plugins that run next to MCEconomy and MCIdentity, and every purchase, sale, and reward moves money through MCEconomy, so all currencies stay consistent across the server.
